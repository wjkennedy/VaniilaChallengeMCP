# Vanilla Forums (Higher Logic Vanilla)

> Vanilla Forums is the cloud community-forum platform now sold as Higher Logic Vanilla. Every Vanilla community serves a REST API (API v2) at /api/v2 with a per-site OpenAPI 3 description, personal-access-token and JWT bearer authentication, webhooks with HMAC-signed deliveries, and an official MCP server (launched May 2026) that connects AI tools to live community data.

Generated by the API Evangelist enrichment pipeline on 2026-07-21 (method: generated — the provider publishes no llms.txt on vanillaforums.com or success.vanillaforums.com; the parent company serves a marketing-oriented one at https://www.higherlogic.com/llms.txt).
